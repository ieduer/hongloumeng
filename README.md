- 真題：北京卷全部涉及《紅樓夢》的 17 道題，含原題、材料、答案來源、詳解
- 人物：44 位人物的判詞、關鍵情節、易錯點與關聯真題
- 詩詞：130 篇詩詞判詞，依回目／人物／類別檢索
- 進度：100／60／30 天三種每日計畫
- 讀法：日常閱讀方法建議與答題模板
