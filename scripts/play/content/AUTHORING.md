# 石頭收服 · 題目撰寫規範

石頭收服（hlm.bdfz.net/play/）是《紅樓夢》考點收服遊戲：一局 10 題、每題 4 個選項、唯一正解，答對收服「石靈」。
讀者是北京的高中生（讀人民文學出版社通行本：前八十回以庚辰本為底本、後四十回程甲本）與臺灣高中生。
目標是幫學生準備北京卷與指考的《紅樓夢》題：人物形象、判詞曲詞、關鍵情節、以詩寫人、伏筆照應、成書常識。

## 一、底本與版本（最重要）

1. 證據只能來自本機 hlm 站資料，比對只看漢字（標點、空白不計）：
   - `data/text/chNNN.json`（`title` 回目＋`content` 正文）：程乙本系統的簡體排印本，有少量錯字。
   - `data/study/poems.json` 的 `lines`／`text`（詩詞；判詞與十二支曲已於 2026-09-17 逐首校訂，判詞以 `data/authored/verdicts.json` 為準）。
   - 真題：`data/study/exams.json`（北京卷，id 如 `bj2021-16`）、`scripts/play/content/exam/zhikao.json`（指考，id 如 `tw-109-20`）。
   - 「書」類卡（成書、版本、紅學）與真題改編題另可引本站撰寫層 `{ "doc": "method" | "people" | "research", "text" }`，但每題至少一條證據要來自原文或真題。
2. **正解必須對通行本讀者也成立。** 底本與通行本關鍵字不同的地方不拿來出題，例如：
   底本「探春住了秋掩书斋」（通行本秋爽斋）、「潦倒不通庶务」（世务）、「孔雀毛的氅衣」（雀金裘）、
   「刘老老」（刘姥姥）、「椿龄画蔷」（龄官划蔷）、「慧紫鹃情辞试莽玉」（忙玉）、「贤宝钗小惠全大体」（时宝钗）、
   「芦雪庭」（芦雪广）、「蒋玉函」（蒋玉菡）。底本第 65 回沒有「多病西施」，這個說法只能用北京卷 2014 題當證據。
   人名、地名、物名在題幹與選項裡一律用通行稱呼（劉姥姥、秋爽齋、雀金裘）。
3. 底本回目錯字（簿命郎、大承苔挞、宝王瞒赃、锦农军、美优怜）不可引用。
4. 拿不準、版本有分歧、學界有爭議的不出。寧可少出，不可出錯。

## 二、檔案格式

一個 JSON 檔：`{ "author": "<你的代號>", "questions": [ ... ] }`。每題：

```json
{
  "id": "a1-qingwen-panci",             // 小寫英數與連字號，全庫唯一；用你的代號開頭
  "card": "s-pc-y1",                    // 掛在哪張石靈卡（見 cards.mjs）
  "kind": "panci",                      // 題型（下表）
  "ch": 5,                              // 這題屬於第幾回（決定落在哪一關）
  "prompt": "這首又副冊判詞寫的是誰？",    // 繁體，70 字內，只問一件事
  "quote": "霁月难逢，彩云易散。",        // 選填：題幹要展示的原文，逐字取自 quoteSrc
  "quoteSrc": { "poem": "又副册判词之一" }, // { "ch": 31 } 或 { "poem": "<poems.json 的 id>" } 或 { "exam": "<真題 id>" }
  "options": ["晴雯", "襲人", "香菱", "金釧兒"], // 正好 4 項；options[0] 是正解（遊戲會洗牌）
  "optionsSource": null,                // 選項若全是原文摘句：4 項來源 [{ "ch": n } | { "poem": id }, ...]，此時選項用原文簡體
  "explain": "……（第五回）",            // 繁體 30–120 字：為何正解成立、關鍵原文在哪回；需要時說易混項為何錯
  "evidence": [{ "ch": 31, "text": "逐字原文" }] // 至少一條，≥6 個漢字，直接支持正解；也可 { "poem": id, "text" } 或 { "exam": id, "text" }
}
```

## 三、題型（kind）

| kind | 問法 | 時限類 |
| --- | --- | --- |
| `alias` 稱號 | 「凤辣子」是誰／誰被稱作「蕉下客」 | 短 |
| `home` 住處 | 誰住瀟湘館／黛玉住哪裡 | 短 |
| `maid` 丫鬟 | 紫鵑是誰的丫鬟 | 短 |
| `flower` 花簽 | 第六十三回黛玉抽到哪種花 | 短 |
| `relation` 親屬 | 薛姨媽是寶玉的什麼人 | 短 |
| `panci` / `panci-line` / `panci-hua` | 整首判詞／判詞一句／判詞畫面 → 人 | 詩 |
| `qu` / `qu-line` | 曲名或曲詞 → 人／曲名 | 詩 |
| `poem-author` / `poem-line` / `poem-occasion` | 誰作的詩／名句出自哪首／在什麼場合作 | 詩 |
| `quote` 言語 | 這句話是誰說的 | 詩 |
| `scene` / `event` / `object` / `place` | 情節中的人、事、物、地 | 情節 |
| `order` / `cause` / `theme` / `book` / `misread` | 先後、因果、主旨、成書常識、常見誤讀辨析 | 判斷 |
| `exam-adapted` | 依真題官方答案要點改編 | 真題 |

## 四、撰寫要求

- 題幹、選項、解析一律**繁體字**（正體），不得出現簡體字；人名用下表。只有 `quote`、`evidence.text` 與標了 `optionsSource` 的選項是原文（簡體，逐字）。
- 正解唯一：三個干擾項同類（人名對人名、地名對地名）、長短相近、看似合理，但依原文明確不對；不出「以上皆是」「以上皆非」。
  同一首判詞寫兩個人（釵黛合一首）時，選項用「林黛玉、薛寶釵」這類成對寫法，不可讓單選一人也算對。
- 題幹不可洩題（例如問「瀟湘妃子是誰」時，題幹不要出現「黛玉」）。
- 解析 30–120 字，要具體：第幾回、哪句原文、為什麼。干擾項若是常見誤解，順帶說一句。
- 一個事實同一方向只出一次；可正反各一（人→物、物→人）。不與規範外的考點重疊太多。
- 內容適合高中生；不出性與暴力細節的題。
- 寫完執行 `node scripts/play/check_facts.mjs <你的檔案>`，直到 `0 with problems`。這只核對引文逐字與格式，**事實是否正確由你負責**。

## 六、考點價值（2026-11-02 第三輪起）

命題前先問：這題考的事實，是否有助理解人物、主線、主旨，或是考試真考過的點？依據本站〈讀法〉第二、八、九條與真題。

- **要出：** 判詞與十二支曲（全部）、全書重要詩詞、見出性格的言行與情節、主要人物結局（後四十回標續書）、重要情節的因果與轉折、住處與園中題名、有文本或脂評依據的地名人名寓意、文化常識（避諱、封號、嫡庶、禮俗、戲曲）、各卷考題涉及的點。
- **不出：** 回目屬第幾回、名次與數目、與性格主線無關的細節、次要人物不重要的一句話是誰說的、同一事實重複出題、無依據的諧音索隱。
- 審核紀錄見 `docs/play/QUALITY.md`。
